LCS CRM — Outlook Add-in Beta

Verknüpft Outlook-Nachrichten direkt mit LCS Projekten, Angeboten und Kontakten. Passender Kontext erscheint automatisch beim Öffnen einer E-Mail.

Funktionen

🎯 Automatische Erkennung

Zeigt passende Projekte und offene Angebote zum Absender — ohne Suchen.

📧 One-Click-Log

Ribbon-Button „Zu Projekt loggen" hängt die E-Mail als Aktivität ans Projekt.

🆕 Lead-Erfassung

Unbekannter Absender? Lead mit einem Klick aus E-Mail-Daten anlegen.

🔍 Projekt-Picker

Mehrere Treffer? Schnellsuche nach Nummer oder Name im Task Pane.

Installation (Outlook Desktop / Web / Mobile)

1

Manifest herunterladen

Die XML-Datei beschreibt das Add-in für deinen Outlook-Client.

⬇️ manifest.xml
2

In Outlook hinzufügen

Wähle Add-Ins verwalten → Eigenes Add-In hinzufügen → Aus Datei…

Alternativ zentral über das Microsoft 365 Admin Center ausrollen (empfohlen für Teams).

3

Einmalig anmelden

Beim ersten Öffnen authentifiziert sich das Add-in über deine bestehende CRM-Session bei lcs.local.

Zentrale Ausrollung (IT)

Für die firmenweite Verteilung via Microsoft 365 Admin Center:

  1. Öffne admin.microsoft.com → Einstellungen → Integrierte Apps
  2. App hochladen → Office-Add-in → URL angeben
  3. Manifest-URL eingeben: 
    https://lcs.local/outlook-addin/manifest.xml
  4. Zuordnung wählen: bestimmte Benutzer / Gruppen / gesamte Organisation
  5. Nach bis zu 12 Stunden erscheint das Add-in in allen Outlook-Clients der zugeordneten Benutzer.

Support & Troubleshooting

  • Add-in lädt nicht: In Outlook-Einstellungen prüfen ob lcs.local als Trusted Domain hinterlegt ist.
  • Keine Treffer obwohl Kontakt existiert: E-Mail-Adresse am Kontakt prüfen (Groß-/Kleinschreibung wird ignoriert).
  • „Zu Projekt loggen" tut nichts: Session in Browser bei lcs.local prüfen — Add-in nutzt SSO-Cookie.
